可直接被生成器读取。目标 exe：`口袋传奇.exe`，MD5 `e2593390d5d8e4bddeaac598a3165e7d`。

- 百分比一律写数字（`6` = 6%），单位看 `unit` 列。
- 全部 TAB 分隔，首行为表头，UTF-8 无 BOM。

| 2 | `0x9E0288` | `0x9E02E4` | 576 | 192 |

| 8 | `0x9E0600` | `0x9E065C` | 576 | 192 |

**命名用位置编号** `A1~A9` / `B1~B9`（非去重编号）。`dup_group` 列标出重复关系：

```
A1 = A3 = A7 = A8     (4 次)
B3 = B7 = B8          (3 次)
其余 11 条互异 → 去重后 A 型 6 种 + B 型 7 种 = 13 种
```

### 三个结构性事实

1. **B 型恰好 13 项** ↔ `refine_grades.tsv` 的精炼"一重~十三重"项数精确一致
2. **A 封顶 576、B 封顶 192**，且 `576 = 192 × 3`
   —— 代码里 B1 读取后有 `lea eax,[eax+eax*2]`（×3），是**代码级证据**，不是数值巧合
3. **A9 尾部 `566,568,570,572,574,576`** 是手工抹平到封顶值
   → **移植照抄，不要用公式拟合**

### ★ 表里是"累计值"，不是"单级值"

反汇编确认（VA `0x8CAD0F`）：

```asm
8B 98 F4 01 9E 00   mov ebx, [eax + 0x009E01F4]   ; A[i]
8B A8 F0 01 9E 00   mov ebp, [eax + 0x009E01F0]   ; A[i-1]
2B DD               sub ebx, ebp                   ; 差值 = 每级增量
```

**光抄数字会错** —— 运行时取的是相邻项差分。差分首项 = `A[0] - 0 = 6`（前一项是 0，干净）。

### ⚠️ 只有 A1 / B1 有绝对地址引用

对 18 条逐条搜索 `.text`，**A2~A9 与 B2~B9 全部命中 0 次**。
其余 8 组可能通过运行时偏移访问（代码里有 `×9` 步长，恰等于组数），
**"9 组全部投入使用"目前只有间接证据**。稳妥做法：**优先照抄 A1 / B1**。

### ⚠️ 关于"A1[1..5] = 6,12,18,24,30 ↔ 技能矩阵"：已降温

初版称两者"逐项精确吻合，是全游戏共享基線"。**此结论已降级为未证实假设**：

- `+6` 等差是最平凡的数字块，且 A4/A5/A6 开头是 `+4`、A9 是 `+12`
  —— **"等差开头"是所有曲线的共同形态**，+6 只是其中一种
- 技能矩阵那 6 组数值在 101 万个 double 位上全阴性

移植时**可以**主动这么设计（设计选择），但**不得声称还原了作者原意**。

## 3. multipliers.tsv —— 乘区 / 常量 / 词条

三部分，用 `offset` 是否为空区分来源：

### ⚠️ 重要修订（v3，2026-09-30）：13 行已删除，31 行降级 🔶

**已删除**：原「倒数比率」13 行（`0x9E0908` 起）。
反汇编证明它是**数学常量**，不是游戏数值：

```asm
8D1156  fld  dword [ecx]
8D115A  fmul st(1)              ; x²
8D1168  fadd qword [0x9E0908]   ; + 1.0   ← [0x9E0908] = 1.0
8D116E  fsqrt                   ; √(x²+1)
8D1170  fdivr qword [0x9E0908]  ; 1.0 / √(x²+1)   ← 归一化
8D1176  fstp dword [eax-8]
```

这是 `1/√(x²+1)` 向量归一化/三角换算，属**运行库数学例程**。
（`0x9E0908` 的 7 次"命中"里还有一次是 `cmp ecx, 0x9E0908` 循环上界，不是数值读取。）

**已降级 🔶**：`乘区系数` / `时间单位` / `经济常量` 三块共 31 行。
理由：这三块的 exe 消费者经反汇编观察为**浮点格式化 / 指数提取 / 数学例程**
（如 `0x873070` 处 `mov ax,[ebp+0xa]; shl ax,1; sub ah,0x7f` 是双精度指数提取；
`0x85C925` 处 `fld [0x9D9018]`=10.0 用于十进制换算）。
且 `10 / 1e4 / 1e5 / 1e6` 恰是这类例程最需要的**十的幂**，
与文档"交易限额1万/飞升丹10万/限购100万"的吻合**很可能是圆数巧合**。

> **处置**：这三块的**数值本身保留**（它们在作者手稿中有明确记载，文档优先），
> 但 `offset` 列**不要当作"该数值存在于此地址"的证据**，`confidence` 列标 🔶。

## 5. ⚠️ 仍然缺失（需要你自己补或用占位公式）

这几项**在 exe 里确实不存在**，已用 101 万个 double 位逐字节全量搜索 + int32 密集块扫描双重确认：

| 缺失项 | 状态 | 建议 |
|---|---|---|
| 怪物 HP / ATK / DEF / 魔御 | ❌ 客户端无 | 用 `monsters_values.tsv` 的等级 + 地图梯度按附录 E.5 公式生成 |
| 怪物经验值 | ❌ 客户端无 | 同上 |
| 怪物爆率 / 掉落阶级 | ❌ 客户端无 | 同上 |
| 装备属性数值 | ❌ 客户端无 | 按 `theme_tier × level_tier` 用 curve A/B 生成 |
| 伤害公式系数 | ❌ 客户端无 | 保留 min-max 区间模型（`攻下/攻上` 双字段） |
| 升级经验曲线 | ❌ 未定位 | **建议直接复用 curve A1（22 项）**，它是作者实际调过手的曲线 |

**能确认的边界**：客户端持有"骨架"（成长曲线、时间单位、经济门槛、乘区基数），
服务端持有"血肉"（怪物属性、爆率、经验、伤害系数）。

若要真数值，只能走**协议逆向**（抓包 + 定位 `WS2_32` 收包函数）。

## 6. 最小接入示例

```python
import csv

def load(path):
    with open(path, encoding="utf-8") as f:
        return list(csv.DictReader(f, delimiter="\t"))

# 成长曲线：按 curve 分组
from collections import defaultdict
curves = defaultdict(list)
for r in load("数值表/growth_curves.tsv"):
    curves[r["curve"]].append(int(r["value"]))

assert curves["A1"][:5] == [6, 12, 18, 24, 30]   # 与技能增伤主线一致

# 技能矩阵：按 (skill, branch) 取 5 阶
sm = defaultdict(list)
for r in load("数值表/skill_matrix.tsv"):
    sm[(r["skill"], r["branch"])].append((int(r["tier"]), float(r["value"]), r["unit"]))
```
